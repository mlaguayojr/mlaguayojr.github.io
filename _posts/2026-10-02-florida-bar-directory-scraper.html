About

Back in 2020, I created a web scraper for the Florida Bar, creatively named Laywer-Directory-Scraper after discovering a Reddit user expressing difficulty on their attempt of creating their own. I'm fond of web scraping, so I figured I'd dive in to learn more about what they're attempting to do and help where I can. Sadly, the original thread content and questions asked by said user is no longer available, but based on the code I previously wrote, it looks like they were attempting to collect the following details:

  • First Name
  • Last Name
  • Email
  • Office Phone
  • Cell Phone

Six years later, does this code still work? 🤔 Hmmm - let's debug!

Modernize Project

First, let's bring this project from proof-of-concept to an actual project. Currently, my preference for managing python projects is uv. Let's make the following changes:

  1. Create uv project: uv init
  2. Pin to latest version of python (at the moment: 3.14): uv python pin 3.14
  3. Add dependencies: uv add bs4 requests

Fix HTTP Client

From past experience, I haven't had to explicitly create a cookie store, but instead had to include some string of a UserAgent to my Request Headers. Adding one will make my request look more like a user request and less like a bot request.
To do so, we can change our request instance from a basic request object, to a Session enabling:

  • Cookie Management
  • Retry logic

While we're looking at the HTTP Client for this site, let's review the site's form to see if the field names and submission route have changed.
